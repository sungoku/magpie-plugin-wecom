企微通知

由 Magpie 异步网关钩子在每轮 Agent 请求结束后推送；Claude Code 的内部搜索/建议侧调用会被跳过，带客户端工具调用的中间回复不会推送。工具调用后若长时间没有下一步请求，会推送“等待确认/选择”提醒。

由 Magpie 插件宿主在本机启动网关（需本仓库已安装依赖；建议先执行 npm run build）。 服务会脱离 Magpie 继续运行；取消勾选不会停止已在运行的服务。
